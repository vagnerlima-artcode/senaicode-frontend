O que é Responsividade?

Responsividade é fazer com que um site consiga se adaptar a diferentes tamanhos de tela.

Um site responsivo funciona bem em computadores, tablets e celulares.

Exemplo

Em um computador, podemos ter vários elementos lado a lado. No celular, eles podem ficar um embaixo do outro.

Conceito

A responsividade permite que o conteúdo de uma página se organize de acordo com o espaço disponível.

Computador

A tela é maior e podemos colocar mais elementos lado a lado.

Tablet

O espaço é menor, então alguns elementos precisam se ajustar.

Celular

A tela é pequena e os elementos geralmente ficam um abaixo do outro.

Por que é importante?

Atualmente, as pessoas acessam sites usando vários tipos de dispositivos.

📱 Celulares

O site precisa funcionar em telas pequenas.

💻 Computadores

O espaço maior permite organizar mais informações.

🖥️ Monitores

O conteúdo pode ocupar melhor o espaço disponível.

Principais técnicas

Existem algumas ferramentas do CSS que ajudam a criar sites responsivos.

Flexbox

Ajuda a organizar elementos em uma linha ou coluna. 

display: flex;

Media Query

Permite mudar o estilo da página dependendo do tamanho da tela. 

@media (max-width: 600px) {
}

Porcentagem

Permite usar tamanhos que se adaptam ao espaço disponível. 

width: 90%;

Viewport

O viewport é a área que conseguimos visualizar na tela.

Para fazer o site funcionar corretamente em celulares, usamos uma configuração importante no HTML: 


<meta name="viewport"
content="width=device-width, initial-scale=1.0">

O que isso faz?

Faz a página utilizar a largura real do dispositivo.

Flexbox

O Flexbox é usado para organizar elementos de forma mais fácil. 


.container {
    display: flex;
}

Com isso, os elementos dentro da classe podem ficar organizados lado a lado.

Media Query

A Media Query permite criar uma regra específica para telas menores. 


@media (max-width: 600px) {

    .cards {
        flex-direction: column;
    }

}

Nesse exemplo, quando a tela tiver até 600 pixels, os cards ficam um abaixo do outro.

Como nosso código funciona?

Nosso projeto utiliza HTML para criar a estrutura e CSS para deixar a página bonita e responsiva.

HTML

O HTML cria títulos, textos, menus, caixas e outras partes da página.

CSS

O CSS define cores, tamanhos, espaçamentos e organização.

Media Query

A Media Query muda algumas regras quando a tela fica menor.

Exemplo do nosso CSS 


.card {
    background: #18202b;
    padding: 20px;
    margin: 10px;
}

Nesse exemplo, criamos uma classe chamada card.

O background muda a cor, o padding cria espaço interno e o margin cria espaço externo.

Conclusão

A responsividade é uma parte importante do desenvolvimento de sites.

Ela permite que uma página se adapte a diferentes tamanhos de tela.
